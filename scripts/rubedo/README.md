# Rubedo validation RNA-seq analyses

Scripts for donor-aware differential expression and antiviral gene set enrichment analyses using an independent primary human lung fibroblast RNA-seq dataset.

The RNA-seq dataset was previously generated and deposited as GEO Series **GSE328392**, part of GEO SuperSeries **GSE328437**.

The original dataset is associated with:

Hughes et al. (2026). *Uncovering senescent fibroblast heterogeneity connects DNA damage response to idiopathic pulmonary fibrosis*. npj Aging. DOI: 10.1038/s41514-026-00388-4

For the current study, a subset of this dataset was reanalyzed using a modified differential expression framework to account for repeated donor measurements. This analysis is used for the independent validation presented in Supplementary Figure 1A.
